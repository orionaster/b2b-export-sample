الجودة والتوثيق

موثقة في كل خطوة.

عملية جودة تصورية للأنابيب عالية النقاء، من الراتنج الوارد إلى عبوة موسومة وقابلة للتتبع.

تدفق إنتاج بسيط.

تصف الخطوات التالية كيفية التعامل مع طلب الإنتاج. وهي ليست ادعاءً بشهادة.

تحقق

يتم فحص الراتنج الوارد وسجلات الدفعات مقابل المواصفة المعتمدة.

بثق

تُراقب خطوط الأنابيب من حيث القطر الخارجي والداخلي وسماكة الجدار.

فحص

تُفحص الأبعاد المرجعية والمظهر قبل التعبئة.

تعبئة

تُوسم الملفات والأطوال المستقيمة وتُحمى وتُعبأ مع ظهور الدفعة.

وثائق يمكن أن يتضمنها طلب الإنتاج.

يتم تأكيد التوثيق لكل منتج ولكل طلب.

شهادة التحليل

ملخص مواد واختبارات على مستوى الدفعة، عند الاقتضاء.

تقرير الأبعاد

قياسات القطر الخارجي والداخلي وسماكة الجدار.

شهادة المادة

درجة الراتنج ومرجع الدفعة، عند توفرها.

سجل التتبع

ملصق دفعة يربط العبوة بسجل الإنتاج.

إقرار المطابقة

إقرار خاص بالمشروع، يتم تأكيده قبل الطلب.

معبأة للخط، وليس فقط للمنصة.

تُوسم الملفات والأطوال المستقيمة وتُحمى وتُعبأ بحيث يبقى المرجع والدفعة ظاهرين.

  • ملف أو طول مستقيم
  • ملصق الدفعة والمرجع
  • غلاف واقٍ
  • كرتون أو صندوق

ما لا يدّعيه هذا المفهوم.

الموقع مفهوم تصميمي، وليس ورقة بيانات منتج.

  • لا يتم الادعاء بأي شهادة.
  • لا يتم الادعاء بأي تصنيف للضغط أو الحرارة.
  • لا تُعرض بيانات اختبار حقيقية.
  • بيانات الشركة والصور توضيحية.
